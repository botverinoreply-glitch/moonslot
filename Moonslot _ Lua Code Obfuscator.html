FAQ

Questions & answers

What is Moonslot? +

Moonslot is a platform built to protect Lua code from theft and unauthorized copying. It transforms your scripts into a protected form that is much harder to read and reverse engineer.

Does the protected code still work? +

Yes. Protection is applied without changing what your script does, so the protected version runs the same way as the original.

Do I need to install anything? +

No. Moonslot runs entirely in your browser. Just sign in, paste your code and copy the result.

How do I sign in? +

Click Get Started and continue with your Google account. It is the only sign-in method available.

Is my code safe on Moonslot? +

Your scripts are processed for protection only. Keep your original files backed up, and always review the protected output before publishing it.
